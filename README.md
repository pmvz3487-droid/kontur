# Контур — сайт фитнес-клуба

Простой одностраничный сайт на чистом HTML/CSS/JS, без фреймворков и сборщиков.

Структура: `index.html`, `js/app.js` (данные, умный фильтр, переключение версий), `css/style.css` (обычная версия), `css/print.css` (версия для печати), `css/lowvision.css` (версия для слабовидящих).

Лабораторная работа №3: умный фильтр расписания (5 критериев: день, время суток, направление, тренер, уровень), версия для печати и версия для слабовидящих. Версии переключаются подменой атрибута `href` у `<link id="theme">` без перезагрузки страницы.

## Как загрузить на GitHub

Через Visual Studio: **Git → Create Git Repository**, выберите GitHub как удалённый репозиторий и опубликуйте.

Чтобы сайт открывался по ссылке вида `https://<логин>.github.io/<репозиторий>/`, включите **GitHub Pages** в настройках репозитория: **Settings → Pages → Source: main / root**.

# Контур — сайт фитнес-клуба

Простой одностраничный сайт на чистом HTML/CSS/JS, без фреймворков и сборщиков.

Структура: `index.html`, `css/style.css`. Расписание и данные занятий находятся в блоке `<script>` в конце `index.html`.

## Как загрузить на GitHub

Через Visual Studio: **Git → Create Git Repository**, выберите GitHub как удалённый репозиторий и опубликуйте.

Чтобы сайт открывался по ссылке вида `https://<логин>.github.io/<репозиторий>/`, включите **GitHub Pages** в настройках репозитория: **Settings → Pages → Source: main / root**.
